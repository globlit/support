SUPPORT · MAC INSTALLATION

Build once. Drag into Applications.

The Mac app provides browser access and notifications. You manage your existing VM separately in Vagrant/Tart.

From your Git checkout

  1. Pull the repository on your Mac and open its folder in Finder.
  2. Double-click Build Support.app. If Apple Command Line Tools are missing, accept Apple's installer, wait for it to finish, then reopen the builder.
  3. The build window downloads a checksum-pinned Node runtime and locked app dependencies, compiles the companion and creates a DMG. It does not change your running app, repositories or Vault.
  4. Click Open installer, drag Support Companion onto Applications, then open it from Applications. You can also find the DMG in the repository's release folder.

No Apple membership, Homebrew, Docker or VM image download is required to build the companion. Building needs Internet access and current Apple Command Line Tools. Installing a previously built DMG needs neither Node nor developer tools.

First launch

The app is ad-hoc signed, not notarized. macOS may block its first launch. Use the per-app Open Anyway control in System Settings → Privacy & Security after attempting to open it. Do not disable Gatekeeper globally.

For Support running on the Mac, select On this Mac · local service, open the existing browser application and pair from Settings → Notifications.

For a VM, open VM connection and choose the folder containing your Vagrantfile. Select the running VM. If you share repositories, select the exact folder under Shared repositories; this grants a read/write exception, including Git metadata. Support discovers SSH settings and shows checks for Mac isolation, the VM identity and the Support service. Expand What to do on an incomplete step, make that change, then Recheck. When the checks pass, click Connect → Open Support.

The app does not create, start or reconfigure your VM. No host profile file is needed. Running Vagrant evaluates your selected configuration on the Mac; keep it outside guest shares.

Updating

Quit the companion before replacing it with the app from a newer DMG. Keychain pairing, your workspace and Vault live outside the app bundle. If macOS asks for notification or Keychain permission again after an ad-hoc rebuild, review that prompt. Do not delete your workspace or reset the Vault.

macOS 13 or later · Apple silicon or Intel · Build on the architecture you intend to use
